# DOCUMENT LIFECYCLE STANDARD

--------------------------------------------------

Document ID

GOV-005

--------------------------------------------------

Purpose

Defines document lifecycle.

--------------------------------------------------

States

Draft

↓

Review

↓

Approved

↓

Released

↓

Deprecated

↓

Archived

--------------------------------------------------

Draft

Initial creation.

--------------------------------------------------

Review

Waiting for approval.

--------------------------------------------------

Approved

Accepted by governance.

--------------------------------------------------

Released

Official repository version.

--------------------------------------------------

Deprecated

No longer recommended.

--------------------------------------------------

Archived

Historical reference only.

--------------------------------------------------

Rules

Released documents cannot be deleted.

Archived documents cannot be modified.

--------------------------------------------------

End
