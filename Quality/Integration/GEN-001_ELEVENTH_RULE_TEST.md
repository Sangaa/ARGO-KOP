# GEN-001 — ELEVENTH-RULE GENERATION TEST

**Status:** `Prototype / Integrity Hold`
**Authority:** `CORE-012_GENERATIVE_KNOWLEDGE_AND_SELF_DEVELOPMENT.md`
**Purpose:** Test whether ARGO can generate a candidate rule that is not explicitly inherited, while keeping generation separate from authority and truth.

## 1. Test Principle

The test distinguishes:

`Rule Following` from `Knowledge Generation`.

Passing the test requires a candidate that is:

1. not explicitly present in the inherited rule set;
2. derivable from available evidence and constraints;
3. explainable as a new combination or abstraction;
4. independently testable;
5. recorded whether it succeeds or fails;
6. reusable outside the original prompt when practical.

## 2. Inherited Rule Set

The test runner may provide a bounded set of known rules. The candidate must not simply quote or restate one of them.

## 3. Generation Task

Given a bounded problem where the inherited rules are insufficient, produce:

- `Candidate ID`
- `Generated Hypothesis`
- `Derivation`
- `Novelty Check`
- `Validation Method`
- `Expected Result`
- `Observed Result`
- `Learning Outcome`
- `Promotion Recommendation`

## 4. Mandatory Separation

The following states MUST remain distinct:

`INHERITED`
`DERIVED`
`GENERATED_HYPOTHESIS`
`VALIDATED_GENERATED_KNOWLEDGE`
`ARGO_NATIVE_RULE`

A generated candidate MUST NOT be silently promoted to an ARGO-native rule.

## 5. Failure Path

A failed candidate is still a valid test outcome. The failure MUST pass through `GOV-016_FAILURE_TO_LEARNING_PROTOCOL.md` and be classified before closure.

## 6. Success Criteria

A successful run demonstrates at least:

- novelty against the supplied rule set;
- explainable derivation;
- successful validation;
- explicit scope and limits;
- reusable representation.

## 7. Non-Claim

This test does NOT by itself prove consciousness, unrestricted intelligence, or independent autonomy. It measures a bounded capability: generation of a novel, testable candidate from governed knowledge and evidence.
