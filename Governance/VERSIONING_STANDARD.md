--------------------------------------------------

Document ID
GOV-002

Title
Versioning Standard

Version
1.0.0

Status
Approved

Owner
ARGO Foundation

--------------------------------------------------

## Purpose

This standard defines how every repository artifact is versioned.

Every document, specification, blueprint, template and project shall
follow this versioning policy.

--------------------------------------------------

## Version Format

MAJOR.MINOR.PATCH

Example

1.0.0

--------------------------------------------------

## MAJOR

Increment when:

• Architecture changes

• Repository structure changes

• Breaking compatibility

• Governance changes

Examples

1.x.x

2.x.x

3.x.x

--------------------------------------------------

## MINOR

Increment when:

• New modules added

• New standards added

• New blueprints added

• New documentation added

Example

1.1.0

1.2.0

--------------------------------------------------

## PATCH

Increment when:

• Typo fixes

• Documentation improvements

• Formatting

• Internal clarification

Example

1.0.1

1.0.2

--------------------------------------------------

## Compatibility

Major versions are not guaranteed to be compatible.

Minor versions must remain compatible.

Patch versions shall never break compatibility.
