# DOCUMENT METADATA STANDARD

--------------------------------------------------

Document ID

GOV-004

--------------------------------------------------

Purpose

Every repository document shall contain metadata.

--------------------------------------------------

Required Metadata

Document ID

Title

Author

Owner

Status

Version

Created

Last Updated

Dependencies

Related Documents

Category

Keywords

Repository Version

--------------------------------------------------

Example

Document ID: GOV-004

Version: 1.0.0

Status: Approved

Category: Standard

Owner: ARGO Foundation

--------------------------------------------------

Metadata Location

Metadata shall always appear at the beginning of the document.

--------------------------------------------------

End
