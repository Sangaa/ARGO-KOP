# Purpose

Defines the mandatory review process for every repository review.

---

# Review Types

- Architecture
- Technical
- Knowledge
- Documentation
- Governance
- Repository

---

# Mandatory Review Sequence

Review

↓

Evidence

↓

Decision

↓

Rewrite

↓

Approval

---

# Mandatory Assessment Requirements

Every review shall include:

- Inspection Scope
- Repository Coverage
- Evidence Classification
- Confidence Level
- Assessment Type
- Repository Version
- Review Date

---

# Evidence Classification

Fact

Verified directly.

Assumption

Requires validation.

Unknown

Evidence unavailable.

---

# Confidence Levels

High

Complete inspection.

Medium

Partial inspection with sufficient evidence.

Low

Limited inspection.

---

# Assessment Types

Approved

Review

Technical Observation

Governance Review

Initial Review

Partial Assessment

The labels:

- Audit
- Complete Review
- Full Assessment

shall only be used after complete repository verification.

---

# Repository Reference

Every review shall identify:

- Repository Version
- Repository State
- Inspection Date

Commit ID when available.
