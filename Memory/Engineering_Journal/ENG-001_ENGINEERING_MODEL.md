# Purpose

This document defines the engineering model used throughout ARGO KOP.

It describes how engineering work is performed, documented, reviewed and preserved.

Unlike Architecture, this document describes the engineering process.

---

# Objectives

The Engineering Model shall:

- Standardize engineering activities.
- Preserve engineering history.
- Support repeatable development.
- Improve engineering quality.
- Ensure complete traceability.

---

# Engineering Philosophy

Engineering follows architecture.

Engineering never defines architecture.

Engineering implements architecture.

Every engineering activity shall be documented.
