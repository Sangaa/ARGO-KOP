# HISTORICAL MEMORY

Status: 🟡 BUILD-01 / INTEGRITY HOLD

Historical Memory preserves past events, decisions, states, lessons and provenance without allowing historical material to silently become current authority.

## Purpose

- preserve continuity;
- retain migration and provenance evidence;
- distinguish historical truth from current repository reality;
- support learning from prior outcomes;
- prevent loss of context during reconstruction.

## Authority Boundary

Historical Memory is evidence and context. It does not override current Constitution, Governance, Architecture, Repository state, or newer validated evidence.

## Core Distinction

```text
Historical Record ≠ Current Fact ≠ Current Authority
```

Historical artifacts may be referenced by current decisions and learning systems, but their historical status must remain explicit.

## Build Boundary

This README establishes the domain contract only. Detailed record, provenance, retrieval and transition rules are defined by subsequent BUILD-01 artifacts.
