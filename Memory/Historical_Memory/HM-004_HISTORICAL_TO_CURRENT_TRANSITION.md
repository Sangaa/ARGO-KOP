# HM-004 — HISTORICAL TO CURRENT TRANSITION

Version: 1.0.0
Status: 🟡 BUILD-01 / INTEGRITY HOLD

## Purpose

Define the boundary between historical memory and current repository knowledge when old material becomes useful for present work.

## Transition States

```text
Historical
  ↓
Reviewed
  ↓
Extracted / Reconstructed
  ↓
Validated
  ↓
Current Candidate
  ↓
Current Authority (only after applicable approval)
```

## No Automatic Promotion

Age, repetition, popularity or previous use does not promote historical material into current authority.

Promotion requires current evidence, identity consistency, applicable governance and relationship validation.

## Preservation Rule

Promotion never requires destruction of the historical source when that source has provenance, migration or learning value.

## Conflict Rule

If historical material conflicts with current validated evidence, the conflict is recorded rather than silently resolving the history to match the present.

## Learning Rule

Historical mistakes and successful outcomes may be converted into lessons or reusable knowledge, but the resulting knowledge must retain a traceable relationship to its historical source.

## Boundary

This transition model prevents historical memory from becoming an uncontrolled back door into current authority.
