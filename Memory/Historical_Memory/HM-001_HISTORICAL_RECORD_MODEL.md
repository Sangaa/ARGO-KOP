# HM-001 — HISTORICAL RECORD MODEL

Version: 1.0.0
Status: 🟡 BUILD-01 / INTEGRITY HOLD

## Purpose

Define the canonical minimum structure for historical memory records.

## Required Fields

- Historical Record ID
- Event / state / artifact description
- Date or time range
- Historical context
- Source / provenance
- Evidence class
- Original status at the time
- Later interpretation, when applicable
- Related decisions or artifacts
- Current relevance
- Superseded / preserved status

## Historical Integrity

The record should preserve what was known, believed or observed at the historical point rather than rewriting the past according to current understanding.

When later evidence changes interpretation, the current interpretation is added as a linked layer instead of silently replacing the historical record.

## Boundary

This model defines historical record structure and does not make historical material current authority.
