# HM-002 — PROVENANCE AND TEMPORAL CONTEXT

Version: 1.0.0
Status: 🟡 BUILD-01 / INTEGRITY HOLD

## Purpose

Preserve where historical information came from and when it was valid, observed or believed.

## Provenance Minimum

A historical record should identify, where available:

- source artifact or person/system;
- creation or observation date;
- capture method;
- repository path or external reference;
- migration history;
- confidence or evidence class.

## Temporal Context

Historical memory must distinguish:

- when something happened;
- when it was recorded;
- when it was interpreted;
- when it ceased to represent current reality.

These timestamps are not interchangeable.

## Migration Rule

When legacy material is reconstructed into a new canonical artifact, the historical source remains traceable. The rebuilt artifact may become current authority only after the applicable validation process.

## Boundary

Provenance strengthens traceability; it does not itself establish correctness or authority.
