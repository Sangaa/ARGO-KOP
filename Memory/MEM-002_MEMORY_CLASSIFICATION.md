# Purpose

This document defines the official classification model for every memory object stored within ARGO KOP.

Memory classification ensures that contextual information remains organized, traceable and reusable.

---

# Objectives

Memory Classification shall:

- Organize repository memory.
- Separate temporary from permanent memory.
- Improve retrieval.
- Support reasoning.
- Preserve long-term context.

---

# Classification Philosophy

Memory is classified by function.

Not by storage location.

Not by technology.

Classification supports reasoning.

---

# Primary Memory Classes

Working Memory

Session Memory

Project Memory

Operational Memory

Decision Memory

Historical Memory

Reference Memory

Archived Memory

---

# Working Memory

Temporary reasoning.

Valid only during execution.

Never repository authority.

---

# Session Memory

Context preserved during one session.

May be promoted after validation.

---

# Project Memory

Project-specific validated memory.

Supports long-term project continuity.

Repository controlled.

---

# Operational Memory

Operational experience.

Reusable organizational practice.

Validated before repository integration.

---

# Decision Memory

Approved decisions.

Decision rationale.

Decision consequences.

Decision history.

---

# Historical Memory

Historical organizational context.

Previous repository states.

Legacy decisions.

Historical events.

---

# Reference Memory

Supporting contextual information.

Indexes.

Mappings.

Cross references.

Reference material.

---

# Archived Memory

Inactive historical memory.

Protected.

Never deleted.

Available for future reference.
