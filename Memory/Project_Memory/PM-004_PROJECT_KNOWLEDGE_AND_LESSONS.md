# PM-004 — PROJECT KNOWLEDGE AND LESSONS

Version: 1.0.0
Status: Build-01 / Integrity Hold

## Purpose

Define how project experience can become reusable knowledge without automatically becoming platform-wide truth.

## Experience Conversion

```text
Project Observation
       ↓
Captured Experience
       ↓
Validated Lesson
       ↓
Reusable Knowledge Candidate
       ↓
Cross-Project Evidence
       ↓
Platform Knowledge Candidate
```

A single project lesson is not automatically a universal rule.

## Lesson Quality

A reusable lesson should preserve:

- original context;
- problem or trigger;
- action taken;
- observed result;
- evidence quality;
- conditions under which the lesson applies;
- known limitations;
- whether it was validated elsewhere.

## Cross-Project Promotion

Promotion from project-local experience to broader knowledge requires evidence beyond the original project when the claim is intended to generalize.

The promotion path must preserve provenance so ARGO can distinguish:

- what happened once;
- what repeatedly worked;
- what is currently believed;
- what has become governed policy.

## Reuse

Project Memory may provide lessons to Knowledge, Decision, Operational Memory or future projects. Consumers must retain the lesson's scope and evidence limitations.

## Boundary

This artifact establishes a knowledge-promotion discipline. It does not create a Knowledge authority model or automatic self-modification mechanism.
