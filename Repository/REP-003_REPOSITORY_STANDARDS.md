# Purpose

This document defines the mandatory standards governing every artifact stored inside the ARGO KOP repository.

These standards ensure repository consistency, maintainability and long-term scalability.

---

# Objectives

Repository Standards shall:

- Standardize repository structure.
- Standardize document quality.
- Eliminate ambiguity.
- Improve navigation.
- Preserve repository integrity.

---

# Repository Principles

The repository is the Single Source of Truth.

Repository content has priority over conversation memory.

Architecture governs organization.

Governance governs standards.

Knowledge remains reusable.

---

# Mandatory Document Structure

Every repository document shall include:

Document Title

Platform

Document ID

Status

Purpose

Content

Related Documents

Guiding Statement

---

# Naming Standard

Every document shall follow:

PREFIX-NNN_NAME.md

Examples

CORE-001_ARGO_MANIFEST.md

ARC-006_DEPENDENCY_MODEL.md

REP-003_REPOSITORY_STANDARDS.md

---

# Ownership Standard

Every document shall have:

One Owner

One Folder

One Canonical Version

Duplicate ownership is prohibited.

---

# Repository Organization

Repository organization follows responsibility.

Technology shall never determine repository structure.

---

# Repository Integrity

Repository integrity requires:

No Duplicate Documents

No Duplicate Ownership

No Hidden Components

No Undefined Dependencies

No Orphan Documents

---

# Version Control

Every repository modification shall:

Increment Version when appropriate.

Preserve Traceability.

Record Architectural Impact.

Update Related Documents when required.

Update Folder Status after approval.

---

# Review Standard

Every repository review shall verify:

Repository Structure

Navigation

Ownership

Dependencies

Naming

Version Alignment

Folder Status

Canonical References

---

# Folder Standard

Every major folder shall contain:

README.md

_FOLDER_STATUS.md

The Folder Status document records:

Current State

Completed Reviews

Outstanding Work

Approval Status

Next Actions

---

# Repository Lifecycle
