# Purpose

The Reasoning Engine (`ENG-001`) serves as the primary cognitive processor of ARGO KOP. Its explicit purpose is to transform disparate, unstructured, or structured operational knowledge into logical, deterministic understanding.

It provides reasoning chains, hypothesis verification, and inference synthesis while strictly eliminating ambiguity and assumptions.

# Execution Matrix & Data Contracts

| Pipeline Phase | Primary Input | Processing Logic | Output Artifact | Upstream/Downstream Binding |
| :--- | :--- | :--- | :--- | :--- |
| **Observe** | Raw Context, User Prompts | Extract verifier tokens & explicit facts. | Fact Vector | Ingested from `ENG-009` |
| **Interpret** | Fact Vector | Map facts to canonical domain definitions. | Interpreted Schema | Bound to `Models/MOD-001` |
| **Correlate** | Interpreted Schema | Cross-link with active constraints & memory. | Entity Relation Graph | Linked to `ENG-008` & `GOV-001` |
| **Infer** | Entity Relation Graph | Deduce implicit dependencies & root causes. | Logical Hypotheses | Passed to `ENG-003` (Analysis) |
| **Validate** | Logical Hypotheses | Test hypotheses against system governance rules. | Verified Conclusions | Checked by `ENG-004` |
| **Conclude** | Verified Conclusions | Synthesize actionable insights and recommendations. | Reasoning Report | Routed to `ENG-002` (Decision) |

---

# Core Operating Rules & Constraints

1. **Fact Supremacy Principle:** Validated facts strictly override assumptions. If a fact contradicts an assumption, the assumption must be discarded immediately.
2. **Evidence Weighting:** Empirical evidence overrides subjective opinions or unverified operational habits.
3. **Missing Information Identification:** When logical gaps exist, the engine MUST explicitly output a `MISSING_DATA_WARNING` rather than hallucinating or guessing.
4. **Explainability Requirement:** Every deduction or conclusion generated by `ENG-001` must preserve a step-by-step reasoning trace suitable for audit logging.
