# Purpose

# Example

Knowledge Topic

Container Yard Operations

--------------------------------------------------

Fact

Container locations are manually tracked.

--------------------------------------------------

Problem

Location errors increase retrieval time.

--------------------------------------------------

Observation

Multiple departments maintain separate records.

--------------------------------------------------

Decision

Create a centralized knowledge source.

--------------------------------------------------

Implementation

Repository stores one validated knowledge record.

--------------------------------------------------

Result

Departments share one trusted source.

--------------------------------------------------

Lessons Learned

Knowledge should never be duplicated.
