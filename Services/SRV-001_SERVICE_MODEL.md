Purpose

This document defines the Services Layer of ARGO KOP.

The Services Layer is responsible for executing operations requested by higher platform layers.

It provides standardized interfaces between ARGO KOP and external systems.

--------------------------------------------------

Mission

Execute.

Never Decide.

Never Govern.

--------------------------------------------------

Responsibilities

Execute approved operations.

Access external systems.

Read and write approved resources.

Return execution results.

Report execution failures.

--------------------------------------------------

Non Responsibilities

Do not perform reasoning.

Do not modify governance.

Do not change repository architecture.

Do not approve decisions.
