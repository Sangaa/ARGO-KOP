# ARGO Knowledge Base

## Purpose

The Knowledge directory contains organized, verified knowledge organized by domain:
- Domain-specific facts and insights
- Analysis and understanding
- Research findings
- Subject-matter expertise

## Directory Structure

Knowledge organized by domain. Each domain includes:

```
Domain-Name/
├── Overview.md          [Domain introduction]
├── Core-Facts.md        [Verified facts]
├── Analysis.md          [Interpretation and insights]
├── References.md        [Sources and citations]
└── SubDomains/          [Specialized subdivisions]
```

## Available Domains

To be populated as knowledge is added to the system.

## Adding Knowledge

### Process
1. Identify the domain
2. Create domain structure if needed
3. Document facts with sources
4. Add analysis and insights
5. Submit for review
6. Publish upon approval

### Quality Standards
- Facts must be verified and cited
- Analysis must be distinguishable from fact
- Assumptions must be explicitly marked
- All sources documented
- Status clearly indicated
