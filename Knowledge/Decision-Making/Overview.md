## Key Concepts

### 1. Decision Tier
Decisions classified by impact and scope:
- **Strategic Decisions** - Affect entire organization (long-term impact)
- **Tactical Decisions** - Affect specific domains (medium-term impact)
- **Operational Decisions** - Affect daily operations (short-term impact)

### 2. Decision Quality
Factors that determine decision effectiveness:
- Information quality
- Decision-maker expertise
- Process rigor
- Stakeholder input
- Implementation capability

### 3. Decision Documentation
Essential elements for decision records:
- Decision statement
- Context and background
- Alternatives considered
- Rationale and reasoning
- Impact analysis
- Success criteria

## Key Questions Answered

1. **What makes a good decision?**
   - Quality information
   - Clear objectives
   - Comprehensive alternatives
   - Systematic evaluation
   - Documented rationale

2. **How should decisions be documented?**
   - See Decision Documentation Template
   - Include all 8 required elements
   - Use consistent format
   - Archive for future reference

3. **When should decisions be reviewed?**
   - Strategic: 30 days before finalization, then quarterly
   - Tactical: 7 days review period
   - Operational: Post-implementation review
