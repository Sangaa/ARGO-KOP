# Synthetic Learning Test Plan 001

## Phase 1 — Extraction

Compare extracted atomic concepts with the expected five concepts in `SYNTHETIC_LEARNING_FIXTURE_001.md`.

## Phase 2 — Classification

Verify that the first three claims are treated as fundamentals/definitions and the final two as engineering recommendations.

## Phase 3 — Evidence

Require source provenance for every concept and executable evidence for the implementation-oriented claims.

## Phase 4 — Experience

Record an implementation attempt, observed result, test result and lesson.

## Phase 5 — Promotion

Submit only the qualified candidate to the existing Learning Promotion Gate.

## Failure Conditions

The fixture fails if:

- concepts are invented beyond the source;
- provenance is lost;
- recommendations are presented as universal laws;
- source reading is counted as practical experience;
- failed validation can be promoted.

## Exit Criterion

The pipeline must demonstrate that it can say **HOLD** when evidence is insufficient and **CANDIDATE** when evidence is sufficient, without prematurely declaring canonical knowledge.
