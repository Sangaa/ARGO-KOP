# Synthetic Learning Fixture 001 — Programming Concept

## Purpose

Provide a tiny, fully controlled learning source for validating ARGO's source-to-knowledge pipeline before introducing a real programming book.

## Source Text

> A function is a named block of reusable instructions. It can accept inputs called parameters and may return a value. A good function should have a clear responsibility and predictable behavior.

## Expected Atomic Concepts

1. A function is a reusable block of instructions.
2. Parameters provide inputs to a function.
3. A function may return a value.
4. Clear responsibility improves understandability.
5. Predictable behavior improves testability.

## Expected Claim Types

- Concepts 1–3: definitions/fundamentals.
- Concepts 4–5: engineering recommendations.

## Validation Fixtures

A candidate learner should be able to produce a small executable function, call it with parameters, observe its returned value, and write a test for expected behavior.

## Integrity

This is a controlled fixture, not an authoritative programming textbook. It is used to test the learning pipeline itself.
