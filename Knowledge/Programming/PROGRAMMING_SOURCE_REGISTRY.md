## Required Metadata

Each future source should record:

- source ID;
- title;
- author/creator;
- edition or version when applicable;
- source location;
- acquisition date;
- intended learning scope;
- extraction status;
- validation status;
- related experiments/tests;
- promotion decision.

## Integrity Rule

A registry entry proves only that a source exists. It does not prove that ARGO has read, understood, validated or learned it.
