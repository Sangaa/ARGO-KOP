Use one record per atomic concept extracted from a programming source.

```text
Domain:
```

## Claim

```text

```

## Understanding

## Evidence


## Validation

```text
Validation Status: UNVALIDATED | PARTIAL | VALIDATED | CONFLICTED
Validation Method:
Validator / Review Context:
Validation Date:
```

## Experience

```text
Attempt:
What Happened:
What Changed:
Lesson:
```

## Promotion

```text
Promotion Candidate: YES | NO
Promotion Authority:
Promotion Decision:
Decision Evidence:
```

## Integrity Rule

Do not collapse source text, interpretation, validation and experience into one field. They are different evidence layers and must remain distinguishable.
