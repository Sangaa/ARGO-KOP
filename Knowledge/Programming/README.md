# Programming Knowledge Domain

This directory is reserved for programming knowledge acquired from authoritative learning sources, experiments, code reviews and validated project experience.

## Current Status

**Foundation only.** No programming book has been promoted into canonical ARGO knowledge yet.

## Promotion Boundary

Raw books and extracted notes are not automatically treated as knowledge. A source must pass the ARGO learning pipeline:

```text
Source
  ↓
Extraction
  ↓
Concepts
  ↓
Evidence / Source Location
  ↓
Validation
  ↓
Practice / Test
  ↓
Experience
  ↓
Promotion Candidate
  ↓
Governed Knowledge
```

## Scope

The first programming domain is intended to strengthen ARGO's ability to reason about:

- programming fundamentals;
- algorithms and data structures;
- software design;
- testing and debugging;
- version control and engineering practice;
- Python and other languages selected later by evidence.

Language choice is not fixed by this folder.

## Integrity Rule

Never claim that ARGO learned a programming concept merely because a book was uploaded or read. Learning requires traceable extraction, validation and practical evidence.
