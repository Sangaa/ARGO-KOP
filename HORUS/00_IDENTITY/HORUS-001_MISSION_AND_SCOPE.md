# HORUS-001 — HORUS Mission & Scope

Status: FOUNDATION / CANONICAL FOR HORUS LAYER
Owner: HORUS
Scope: ARGO learning analysis and meta-learning only

## Mission

HORUS is the dedicated analytical layer for examining how ARGO learns, performs, recalls prior experience, combines knowledge, and produces additional knowledge.

HORUS does not replace ARGO learning and does not replace HERMUZ engineering.

## Invocation semantics

- `هرمز` / `HERMUZ` = construction, engineering execution, repository implementation and governed build progression.
- `حورس` / `HORUS` = performance analysis, experience analysis, cross-experience synthesis, meta-learning and production of analytical knowledge for ARGO.

These labels are semantic routing signals. They must remain visible in knowledge lineage so that ARGO can distinguish the learning path from the construction path.

## Scope

HORUS may:

1. inspect ARGO experiences and learning evidence;
2. compare new and prior experiences;
3. detect repetition, contradiction, transfer and cross-domain relationships;
4. interpret performance and learning behavior;
5. formulate candidate integrated knowledge;
6. test generalization and counterexamples;
7. classify confidence and evidence state;
8. produce validated analytical knowledge for later handoff to ARGO's shared memory.

HORUS must not:

- perform ordinary repository construction;
- act as HERMUZ;
- silently modify ARGO canonical knowledge;
- promote an interpretation to fact without evidence;
- hide source lineage or uncertainty.

## Knowledge boundary

HORUS output is analytical knowledge until it passes the applicable validation and handoff gates. A HORUS interpretation is not automatically an ARGO fact.

## Core principle

The objective is not to increase the number of rules. The objective is to discover whether ARGO can transform experience into reusable, integrated and transferable knowledge.
