## New analytical construct — IGT (Invariant Generalization Test)

For a learned rule R, decompose R into invariants I1..In. Construct novel cases that vary surface details while preserving exactly one or more invariants. Require a pre-action prediction and a post-action explanation. Score separately:
- invariant identification;
- authority selection;
- scope preservation;
- action selection;
- evidence quality;
- explanation fidelity.

A case passes only when the behavior is correct for the relevant invariant and the explanation does not exceed evidence scope.

## New analytical construct — LPE (Learning Provenance Envelope)

Every promoted learning candidate should carry:
`SOURCE_CASES → OBSERVATIONS → INVARIANTS → EXCLUDED_INTERPRETATIONS → TRANSFER_CASES → PREDICTIONS → VERIFICATIONS → FAILURES → REVISION → PROMOTION_STATUS`.

This prevents a later agent from seeing only the polished rule and losing the negative evidence that defined its limits.

## New analytical construct — Failure-as-knowledge rule
A failed transfer case should be preserved if it identifies a boundary condition. The useful transformation is:
`Failure → Boundary → Revised Invariant → New Test`.
A failure that cannot identify a boundary remains unresolved evidence, not a learning gain.
