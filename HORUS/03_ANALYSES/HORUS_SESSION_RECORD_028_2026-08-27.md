## Deep analytical findings

### F-H028-01 — The evidence boundary is now the experiment itself
The project has progressed from defining what learning would mean to defining what evidence would make a learning claim admissible. This is an epistemic boundary: without pre-observation prediction and baseline identity, a result can be correct while remaining non-diagnostic.

### F-H028-02 — Evidence contamination can create false learning
If the evaluator sees the expected authority rule or target outcome, correct behavior can result from instruction following rather than transfer. Therefore leakage control is not an administrative detail; it is a causal prerequisite for interpreting the result.

### F-H028-03 — Baseline identity is part of the evidence, not metadata
A measured improvement has meaning only relative to a precisely identified baseline. `L1 succeeds` is weak. `L1 > B0 under the same task family and controls` is stronger. Without baseline provenance, improvement cannot be attributed.

### F-H028-04 — Prediction-before-observation increases evidentiary strength
A pre-observation prediction creates a falsifiable commitment. Post-hoc explanations cannot substitute for it because the system can otherwise adapt its explanation to the observed answer.

### F-H028-05 — Negative results are first-class learning evidence
An independent IGT failure can reveal that the invariant was too broad, the transformation was not truly analogous, the baseline was stronger than assumed, or the candidate knowledge did not transfer. Each outcome can refine the knowledge boundary without becoming a system failure.

## New analytical construct — ECI (Evidence Causality Index)

HORUS defines an evidence-quality vector rather than a single PASS/FAIL:
`I = Independence`
`B = Baseline integrity`
`P = Prediction-before-observation`
`L = Leakage control`
`V = Independent verification`
`S = Scope fidelity`
`R = Reproducibility`

A learning claim should not be promoted merely because the task outcome is correct. The evidence profile must show which dimensions are satisfied and which remain weak.

## New analytical construct — LAA (Learning Attribution Analysis)

For every apparent improvement:
1. Compare against identified baseline.
2. Check whether the candidate had access to additional information.
3. Check whether the expected answer leaked.
4. Determine whether the behavior transferred through invariant structure rather than surface similarity.
5. Repeat on a second novel case.
6. Record alternative explanations.
7. Assign the strongest claim supported by evidence, not the strongest imaginable claim.

Claim ladder:
`Correctness → Transfer Evidence → Generalization Evidence → Learning Improvement Evidence → Meta-Learning Candidate`.

## New test discipline — Counterfactual Baseline Pair
Where practical, evaluate two matched cases: one with the candidate learning available and one baseline condition without the candidate-specific learning, while keeping surface complexity comparable. This does not prove causality alone, but it reduces the chance that generic capability is mistaken for learning-derived improvement.
