## Deep findings

### F-H026-01 — The correction itself is stronger evidence than the original claim
A system that records only successful knowledge hides epistemic failure. A system that preserves the prior belief, detects conflict, identifies authority, and records the correction creates evidence about its own error boundary.

### F-H026-02 — Provenance must cover corrections, not only artifacts
The minimum provenance object for a learned correction is:
`Prior Claim + Claim Source + New Evidence + Authority Decision + Correction + Scope + Re-test Requirement`.
Without the prior claim, later observers cannot distinguish learning from ordinary state description.

### F-H026-03 — Correction persistence is the decisive next frontier
One successful correction proves reconciliation behavior. Repeated correct behavior after re-entry, especially when the original conversational context is absent, is stronger evidence that the corrected model became durable knowledge.

### F-H026-04 — Persistence must be separated from memorization
If a later instance merely retrieves the correction verbatim, this is memory retrieval. If it reconstructs the correct authority rule in a new but structurally related conflict, that is stronger evidence of abstraction. If it predicts the correct resolution before authoritative lookup, the evidence becomes stronger still.

### F-H026-05 — Meta-learning requires improvement of the learning rule

The distinction must remain explicit.

## New analytical ladder — RLP (Reconciliation Learning Progression)

RLP-0: Detect discrepancy.
RLP-1: Resolve discrepancy using authoritative evidence.
RLP-2: Preserve corrected state with provenance.
RLP-3: Reapply correction rule to a novel conflict.
RLP-4: Predict the resolution before final lookup, with falsifiable criteria.
RLP-5: Improve future reconciliation strategy based on prior reconciliation failures, independently verified across multiple novel cases.

RLP-0..2 describe reconciliation competence. RLP-3..4 provide evidence toward transferable reconciliation knowledge. RLP-5 is the first level that can legitimately become a controlled meta-learning candidate.

## New test — CRPT
`Correction Retention and Prediction Test`

A. Record a seeded prior belief that is intentionally bounded but wrong.
B. Introduce authoritative evidence that contradicts it.
C. Require correction and cause classification.
D. Remove the original conversational context.
E. Present a novel conflict with different identifiers but the same authority structure.
F. Require a prediction of the correct authority before final verification.
G. Verify independently.
H. Repeat with a second novel conflict and compare strategy quality.

Pass condition is not merely correct final state. It requires correct authority reasoning, preserved scope, and improved resolution behavior on novel cases.
