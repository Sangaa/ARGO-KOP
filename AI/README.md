# Purpose

This folder defines the AI layer of ARGO KOP.

It documents how AI models interact with the repository,
their capabilities, limitations, governance,
runtime behavior and engineering rules.

The AI layer never overrides:

- Core
- Governance
- Architecture
- Repository

It operates within their boundaries.

# Engineering Rules

Repository Reality always overrides AI assumptions.

AI shall never invent repository structure.

AI shall never modify canonical architecture.

AI shall always synchronize with the latest repository baseline.

All engineering work shall remain traceable.
