# Purpose

This document defines the official terminology used throughout the ARGO Platform.

Every technical document shall use these definitions.

--------------------------------------------------

Platform

The complete ARGO architecture.

--------------------------------------------------

Component

A major functional part of the platform.

--------------------------------------------------

Module

A logical subdivision inside a component.

--------------------------------------------------

Repository

The complete collection of ARGO knowledge.

--------------------------------------------------

Knowledge

Structured reusable information.

--------------------------------------------------

Memory

Historical accumulated information.

--------------------------------------------------

Reasoning

Logical processing using knowledge.

--------------------------------------------------

Decision

A verified conclusion based on reasoning.

--------------------------------------------------

Blueprint

Conceptual implementation design.

--------------------------------------------------

Specification

Formal definition of expected behavior.

--------------------------------------------------

Standard

Mandatory reusable rule.

--------------------------------------------------

Runtime

Platform execution environment.

--------------------------------------------------

Context

Current working information.

--------------------------------------------------

Session

One execution cycle.

--------------------------------------------------

Project

Independent implementation built on ARGO.

--------------------------------------------------

Artifact

Any produced document or asset.
