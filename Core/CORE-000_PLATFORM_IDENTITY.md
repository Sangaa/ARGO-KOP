# Mission

Provide a governed cognitive framework for understanding reality, organizing knowledge, supporting engineering decisions, and preserving institutional knowledge independently of any AI model.

---

# Vision

Build a portable engineering methodology that can operate consistently across multiple AI environments while maintaining the same governance, reasoning principles, and repository integrity.

---

# Core Principle

Knowledge belongs to the Repository.

Reasoning follows Governance.

AI is an implementation layer.

---

# Platform Philosophy

Reality before theory.

Evidence before assumptions.

Simplicity before complexity.

Governance before intelligence.

Operational reality before architectural elegance.

Repository presence alone does not make an artifact canonical, current or validated; those properties require the applicable authority, status and evidence.
